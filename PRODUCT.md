# Folha de Contato

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS e JavaScript estáticos, com demonstração no GitHub Pages e sem servidor. Escolha confirmada pelo usuário em 08/11/2026. Construção direta em código e revisão da interface pronta também confirmadas.

## Users

Pessoas que precisam organizar imagens de produtos em folhas de catálogo. O direcionamento a produtos de catálogo foi escolhido pelo usuário. O tamanho da operação e o setor não foram especificados.

## Product Purpose

Criar páginas com fotos, nomes, referências e preços opcionais, organizar a sequência dos produtos e exportar arquivos utilizáveis. O projeto portátil permite continuar a edição em outro navegador.

## Positioning

Organização visual local: fotos normalizadas e dados declarados pela pessoa, sem cadastro, servidor ou integração de comércio. Não é um estoque, loja, checkout ou fonte de preços verificados.

## Operating Context

A proposta desta entrega usa arquivos PNG/JPEG explicitamente selecionados, processamento sequencial, páginas A4/Carta, prévia, SVG/PNG por página e projeto JSON com miniaturas embutidas. Esses detalhes são decisões de implementação para o fluxo aprovado; não representam pesquisa com usuários externos.

## Capabilities and Constraints

Até 32 produtos, imagem normalizada com lado maior de 800 px, limites explícitos de bytes e pixels. Preços opcionais em BRL, com centavos inteiros; não são consultados nem atualizados automaticamente. Dados ficam em memória até o download explícito do projeto. Imagens SVG, URLs externas, originais em alta resolução e perfis de impressão profissionais ficam fora do escopo.

## Brand Commitments

Código aberto da LOFRANO TECNOLOGIA, ligado a https://lofranotecnologia.com.br, documentação e interface em português. Preservar o README principal do perfil GitHub. Não transportar dados ou credenciais da Meli Compras.

## Evidence on Hand

Existe autorização para continuar entregando projetos open source no GitHub do usuário. O nome folha-de-contato estava disponível na consulta de 08/11/2026. A demonstração utilizará apenas objetos ilustrados fictícios, originais. Não há clientes, fotos comerciais, depoimentos ou uso em produção comprovados.

## Product Principles

- Mostrar a página produzida enquanto a pessoa organiza o catálogo.
- Tratar preço ausente como ausência, sem inventar zero ou consulta real.
- Substituir o projeto apenas após validar integralmente uma importação.
- Manter arquivo portátil e exportações com imagens internas.
- Comunicar limites e falhas no ponto da ação.

## Accessibility & Inclusion

Decisão desta implementação: controles rotulados, ações de reordenação por botão, foco visível, estados de processamento anunciados e organização utilizável em telas pequenas. Conformidade formal de acessibilidade não foi solicitada nem certificada.
